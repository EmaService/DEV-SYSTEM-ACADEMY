# MES 2 — Git, GitHub y el trabajo real con código
## Temario completo (90 lecciones)

**Estructura:** igual que el Mes 1 — 3 materias en paralelo, 1 lección de cada una por día (3 diarias ≈ 2 horas), 30 días de contenido + examen del mes + proyecto.

**Por qué este mes es el más importante del programa:** en el Mes 1 el alumno construyó su primera página con IA. Pero la guardó en una carpeta suelta, sin historial, sin respaldo, sin forma de volver atrás. Este mes le enseña el sistema nervioso de TODO el software profesional del mundo. Después de este mes, el alumno deja de ser alguien que "le pide cosas a la IA" y se convierte en alguien que **dirige un proyecto de software real**.

**Materias del Mes 2:**
- **Materia A — Git: la máquina del tiempo** (control de versiones desde cero)
- **Materia B — GitHub: la plaza pública del código** (colaboración, PRs, portafolio)
- **Materia C — Construye con IA II: tu proyecto versionado** (práctica real de principio a fin)

## Cierre del Mes 2

- **Examen del Mes 2:** 30 preguntas mezclando las 3 materias
- **Proyecto final:** un repositorio público en GitHub con: README profesional, al menos 10 commits con mensajes claros, una rama de feature mergeada vía Pull Request, y el sitio publicado con GitHub Pages. El alumno entrega la URL del repo y la URL del sitio vivo.

## Conexión con el Mes 1

Todo lo que el alumno construyó en el Mes 1 (su página personal, su página de negocio) se convierte este mes en repositorios versionados y publicados. No hay trabajo tirado: el Mes 2 toma lo del Mes 1 y lo profesionaliza.
