# MES 3 — La web por dentro: interfaces que se ven bien y funcionan
## Temario completo (90 lecciones)

**Estructura:** 3 materias en paralelo, 1 lección de cada una por día (3 diarias ≈ 2 horas), 30 días + examen del mes + proyecto final.

**Qué cambia este mes:** en el Mes 1 el alumno entendió el mundo digital; en el Mes 2 aprendió a versionar y publicar. Este mes aprende a **ver una interfaz por dentro**. Deja de pedir "hazme una página bonita" y empieza a pedir "usa grid de 3 columnas que colapse a 1 en móvil, con jerarquía tipográfica de 3 niveles y estados de carga". Esa precisión es la diferencia entre una IA que adivina y una IA que ejecuta.

**Materias del Mes 3:**
- **Materia A — Maquetación: HTML y CSS a fondo** (la estructura y el estilo)
- **Materia B — JavaScript en el navegador** (la interactividad y los datos)
- **Materia C — Construye con IA III: interfaces reales** (práctica de principio a fin)

## Cierre del Mes 3

- **Examen del Mes 3:** 40 preguntas mezclando teoría y práctica de las 3 materias
- **Proyecto final:** una web app real de un negocio, publicada y versionada, que incluya: layout responsive con Grid o Flexbox, dark mode, un catálogo pintado desde datos (no HTML escrito a mano), buscador o filtro funcional, formulario de contacto conectado, los tres estados de interfaz manejados, y meta tags para compartir. Se entrega la URL del sitio y la del repositorio.

## Conexión con los meses anteriores

El proyecto del Mes 3 vive en un repositorio de GitHub (Mes 2) y se publica con GitHub Pages o Netlify (Mes 1 y 2). Nada de lo aprendido se abandona: cada mes agrega una capa sobre la anterior.

## Lo que el alumno podrá hacer al terminar

Abrir cualquier sitio web, inspeccionarlo, entender cómo está construido, y pedirle a una IA que replique esa estructura con el vocabulario correcto. Es el mes donde el alumno deja de ser espectador de las interfaces y empieza a leerlas.
